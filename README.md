# The Blacklist — Intelligence Board

Fan-made interactive companion for watching The Blacklist together, currently spoiler-locked to **Season 1 Episodes 1–8**.

## Launch

Enable GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

Your public website will then be: https://cchambruhs.github.io/blacklist-intelligence-board/

## Features

- Clickable character and clue relationship board
- Episode recaps, biggest discoveries, and bigger-picture context
- Blacklist registry unlocked in episode order
- Unresolved mystery tracker
- Mobile-responsive standalone HTML with no dependencies
- Viewing position saved separately in each device's browser

## Spoilers and accuracy

Only episodes 1–8 are implemented. Selecting an episode shows developments up to that episode, but the initial viewing position defaults to episode 8. Recaps are concise summaries and may omit subplots. This is an independent fan project, not affiliated with the show's producers.
